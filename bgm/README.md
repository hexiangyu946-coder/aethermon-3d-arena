# 🎵 自定义原声 BGM 文件夹 (支持《宝可梦 朱／紫》MP3)

将你喜欢的 MP3 音乐文件重命名为以下文件名并上传到本 `bgm/` 目录，游戏部署后即可自动识别并播放：
- `bgm/town.mp3` — 城镇 / 商店 / 队伍整理背景音乐（例如：桌台市）
- `bgm/field.mp3` — 帕底亚开放世界原野探索背景音乐（例如：南第1区）
- `bgm/mystic.mp3` — 第零区 / 极光雪山 / 星坠谷探索音乐（例如：第零区）
- `bgm/battle_wild.mp3` — 野生星灵对战音乐
- `bgm/battle_boss.mp3` — 道馆馆主 / 传说宝主 / 联机 PvP 激战音乐
- `bgm/battle_terastal.mp3` — 太晶化高潮决胜音乐

（未上传 MP3 的场景会自动回退使用内置多声道混响合成器配乐，也可在游戏右上角「🎧 换原声MP3」直接选择手机/电脑本地 MP3 试听。）
